# Knights College Cursor v1.4.0

This release adds three ready-to-install Default-size animated cursor packs for
Windows: Argo, Grantly, and Oscar. It also includes an approximately 40-second English showcase
video featuring all three characters.

## Downloads

- `ArgoCursor-v1.0.0-Windows-Default-by-Neilzou1.zip`
- `GrantlyCursor-v0.1.0-Windows-by-Neilzou1.zip`
- `OscarCursor-v0.1.1-Windows-Default-by-Neilzou1.zip`
- `Argo-Grantly-Oscar-Cursor-Showcase-EN-v1.mp4`
- `Argo-Grantly-Oscar-Cursor-Showcase-EN-v1-contact-sheet.png`

Extract a cursor ZIP completely before running its BAT installer. Each pack
contains 13 ANI files, 13 CUR fallbacks, 13 transparent GIF previews, and
current-user install, apply, restore, and uninstall helpers.

## macOS With MaCursor

These downloads use Windows `.cur` and `.ani` files. On macOS 15 Sequoia or
later, [MaCursor](https://github.com/writronic/MaCursor) can convert them into
a native macOS cursor theme:

1. Install the latest MaCursor `.dmg` from its Releases page.
2. Download and fully extract the Argo, Grantly, or Oscar ZIP.
3. In MaCursor, choose **File -> Convert Theme...** (`Shift-Command-O`) and
   select the extracted character folder containing the `.inf` file and
   `cursors` folder.
4. Review **Mapped** and **Warnings & ignored**. Use **Add & Edit...** if you
   want to check the mapping, animation, or hotspots first.
5. Click **Add to Library**, select the imported theme, and click **Apply**.
6. Optional: install the **Helper Tool** from **MaCursor -> Settings ->
   General** so the theme is reapplied after login or a user switch.

Use MaCursor's **Restore** button to return to the default macOS cursors.
MaCursor is a third-party application and is not bundled with this project.

## Validation And Privacy

- Every public ZIP passed CRC and full extraction checks.
- Every cursor ZIP contains exactly 13 ANI files, 13 CUR files, and 13 GIF
  previews.
- Public package reports use relative package names instead of local volume or
  home-directory paths.
- Public copies exclude `.DS_Store`, AppleDouble files, personal email
  addresses, local account names, and machine-specific paths.
- Repository commits use the existing public GitHub identity and noreply email
  address.

Earlier character downloads remain available from their existing release
pages.
