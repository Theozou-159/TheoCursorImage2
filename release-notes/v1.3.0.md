# Knights College Cursor v1.3.0

Li Jun joins the Knights College Cursor collection with a complete Default-size
animated cursor pack for Windows.

## New Download

- `LiJunCursor-v1.0.1-Windows-Default-by-Neilzou1.zip`

This ZIP contains 13 animated cursor states, one-click install and apply
helpers, an install-only option, a cursor-scheme backup restore helper, and an
uninstaller.

## What Is New

- Added Li Jun's complete Windows animated cursor set.
- Added the transparent six-frame Pointer idle preview to the repository home
  page.
- Included the accepted eight-frame motorcycle animation for Precision Select.
- Corrected the Precision Select hotspot from the canvas center to the painted
  crosshair center at `(38, 38)`.
- Kept the Move animation and the other approved cursor states unchanged.

## Install

1. Download `LiJunCursor-v1.0.1-Windows-Default-by-Neilzou1.zip`.
2. Extract the ZIP completely.
3. Run `Apply-LiJun-Cursors.bat` to install and switch immediately, or run
   `Install-LiJun-Cursors.bat` to register the scheme without switching.
4. To switch later, open **Mouse Properties** -> **Pointers** and choose
   `Li Jun Cursor`.

The package installs for the current Windows user under:

```text
%LOCALAPPDATA%\LiJunCursor\Cursors
```
