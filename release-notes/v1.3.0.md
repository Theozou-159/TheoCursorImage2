# Knights College Cursor v1.3.0

This release now brings together the latest Diderich, Theo, and Li Jun
Default-size animated cursor packs for Windows.

## Downloads

- `DiderichCursor-v1.1.6-Windows-Default-FunctionalHotspotFix-by-Neilzou1.zip`
- `TheoCursor-v2.0.0-Windows-Default-by-Neilzou1.zip`
- `LiJunCursor-v1.0.1-Windows-Default-by-Neilzou1.zip`

Each ZIP contains 13 animated cursor states and current-user Windows install
helpers. Extract a ZIP completely before running its install or apply BAT file.

## Diderich v1.1.6

- Uses the approved dynamic paw markers for Pointer, Link, and Move.
- Keeps the Help and Link character-animation swap while preserving each
  role's functional marker.
- Removes the leaked Horizontal Resize arrow fragment.
- Stabilizes the Precision Select and Unavailable character animation.
- Corrects Precision Select from the canvas-center hotspot to the functional
  crosshair center at `(38, 34)`.
- Keeps role-specific hotspots for Move and every resize direction.
- Includes 13 transparent GIF previews.

Install and apply immediately with `Apply-Diderich-Cursors.bat`, or register the
scheme without switching with `Install-Diderich-Cursors.bat`.

## Theo v2.0.0

- Rebuilds all 13 cursor roles from approved transparent frame sets.
- Uses the locked Pointer R2 character pose without whole-body horizontal
  drift.
- Uses the approved R3 dynamic four-way marker for Precision Select.
- Uses Theo's measured stripe color `#B69176` for Cross and resize markers.
- Binds Cross and resize hotspots to their real functional markers instead of
  the canvas center.
- Includes 13 ANI files, 13 CUR fallbacks, all 15 traditional Windows scheme
  slot mappings, transparent previews, and 32/48/64px review material.

Install with `Install-TheoCursor-v2-Cursors.bat`. This registers the rebuilt
scheme without switching automatically. Use `Apply-TheoCursor-v2-Cursors.bat`
only when you want to install and switch immediately.

## Li Jun v1.0.1

- Includes Li Jun's complete 13-state Windows animated cursor set.
- Keeps the accepted eight-frame motorcycle animation for Precision Select.
- Corrects the Precision Select hotspot to the painted crosshair center at
  `(38, 38)`.
- Includes the transparent six-frame Pointer idle preview on the repository
  home page.

Install and apply immediately with `Apply-LiJun-Cursors.bat`, or register the
scheme without switching with `Install-LiJun-Cursors.bat`.
